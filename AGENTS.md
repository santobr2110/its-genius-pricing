
- Observability pricing has two isolated models (classic UM bands vs levels M1–M4 + NVPS) selected by `modeloObservabilidade`; only one ever produces monitoring cost — keeps saved pricings unchanged.
- Shared pricing lives in `src/lib/pricing/`: every offering computes the markup-divisor cascade through `cascataNucleo` with its own declared `REGRA_*` edge rule (Σ ceiling, divisor form, sum order) — rules reproduce historical results and must not be harmonized. Tax rates for every offering come only from `tax_product_codes`/`tax_product_code_rates` (via `useTaxCodes` + `resolveTaxRates`, UI in `ProdutoFiscalCard`); the legacy static/localStorage code table was removed — one official source, managed in Admin.
- `src/test/naoRegressao.test.ts` snapshots Smart ITO, BodyShop and M1–M4 results; never update those snapshots to make a change pass — protects existing pricing.
